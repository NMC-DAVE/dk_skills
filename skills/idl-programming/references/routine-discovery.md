# 函数发现与版本核对

## 查找顺序

1. 当前任务代码及接口：先找已有实现和项目约定，再选择新的 API。`search ... --project` 只索引项目 `.pro` 的例程声明；返回文件和行号。它不是完整语法解析器，条件编译、动态调用或同名例程需要阅读源码确认。
2. 官方 IDL 索引：按名称片段与类型查询。自然语言需求可先变为英语技术词，例如 interpolation、Fourier transform、missing values。名称不匹配时使用 `search "Fourier transform" --text` 搜索本机文档正文。
3. `docs NAME --type TYPE`：阅读本机正文，核对调用语法、参数、关键词、示例、返回值及版本历史。类方法使用 `ClassName::MethodName`。官方和项目同名时直接读取项目来源，避免混淆。

上游索引是 6.2.2 的发现快照，含 2761 个命名条目；`internal` 指插件来源分类，不表示内部 API 一律可用。API 是否公开、过时或需要额外模块，以本机正文为准。索引中的路径可能在另一安装版本不存在。

## 版本适配

- `doctor` 的实际版本决定兼容目标。索引不提供完整的 minimum-version 元数据，不能将“索引中存在”当作“IDL 9.3 支持”。
- 默认从 `!DIR/help/online_help/Subsystems` 读取文档。保留 `Version History` 表中例程或关键词的新增/修改记录，不能仅比较例程首次出现的版本。
- 文档中未知的版本、没有历史记录或仅找到当前在线文档时，报告证据边界；通过编译和最小测试核对选中的实际调用。
- 新版 API 若缺少快照条目，可按名称在本机帮助中寻找同名主题；找不到时由 agent 在本机官方帮助中进一步搜索。不要让旧索引限制运行时升级后的能力。
- 本机帮助缺失时，使用脚本给出的官方在线链接或在 [NV5 Docs Center](https://www.nv5geospatialsoftware.com/docs/) 搜索。在线文档版本可能比本机新，检查版本历史与实际测试。脚本不自动联网下载或打包官方手册。

## 外部库

默认范围为官方 IDL 和当前任务项目，不能自动扫描或推荐全部 `!PATH` 中的个人库。用户点名某库后，使用其根目录作为 `--project`，读取例程声明、文档与源码，并通过 `--include` 添加实际所需目录。返回时区分官方、项目和第三方依赖；文件存在不证明已经加载或行为兼容。

ENVI、IMSL 等库可能需要额外安装和许可，只有任务需要时才核对。IDL 启动成功不能证明这些模块可用。
