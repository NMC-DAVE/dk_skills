# 风格档案目录

本目录是一份"风格档案"——从某个来源（某位领导、某单位、某作者）的样文中提取的可复用写作风格规则集。档案建好后，写作或改写前重读本目录全部文件，再按档案执行。

## 目录结构

```text
<来源名称>/                  # 如 style-profiles/张书记/
├── raw/                    # 样文原文（.md 或 .txt）
│   └── YYYY-MM-DD 体裁 场合或标题.md
├── _meta/
│   └── 语料登记表.md        # 每篇样文的元数据，跨篇对比的依据
├── 语言DNA.md              # 用词、句式、称呼自称、语气、标点
├── 结构模板.md              # 按体裁分列的结构骨架与过渡句式
├── 立场与认知.md            # 议题侧重、表述口径库、素材与引用偏好、核心命题
├── 排版规范.md              # 标题编号体系、标题风格、段落节奏、格式惯例
└── 风格DNA.md              # 整合总入口（写作前必读，≤3500字）
```

## 使用方式

**写作前**（模式 B/C 的固定动作）：

1. 读 `风格DNA.md` + 四份分层产物，一份不跳。
2. 从 `raw/` 选 2-3 篇与本次任务体裁、场合最接近的样文通读（按登记表筛选；语料少就全读）。
3. 按档案写作或改写，最后用去AI味白名单清理（见 `references/anti-ai-tone.md`）。

**档案维护**：

- 用户纠正过的口径或风格偏好，随手补进对应分层产物，档案越用越准。
- 拿到新样文时：存入 `raw/`、更新登记表、复核并更新四份产物与整合文档。
- 语料变化导致某条规则失效时，删除或降级该条，并在置信度说明中记录。

## 提取规范

分层产物的提取细则见 `references/analysis-guide.md`，体裁差异见 `references/genre-guide.md`。要点：

- 每条规则附原文例证，逐字摘自 `raw/` 并标注来源文件。
- 区分主题词与语风词。
- 置信度三级（确证 / 观察 / 推断）逐条标注，产物末尾附覆盖说明。
