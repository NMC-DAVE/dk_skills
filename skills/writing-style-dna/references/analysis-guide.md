# 分层提取操作细则

本文件是模式 A（提取建档）Step 4 的操作依据。四份分层产物各有一节，说明提取什么、怎么提、写成什么样。

## 总则

1. **每条规则必须带原文例证**：逐字摘自 `raw/`，标注来源文件名。摘录控制在一两句，不必整段。
2. **区分主题词与语风词**：语料反复出现"项目""安全"可能只是因为话题集中（主题词）；反复出现"抓实""见效"才是语风词。语言DNA只收语风词。
3. **宁缺毋滥**：只在 1 篇中出现过、且无法判断是语风还是偶然的特征，降级为"推断"或不写。
4. **小语料不做机械词频统计**：2-10 篇语料跑"前 100 高频词"没有意义。逐篇精读标注，汇总出"最能代表此人"的 30-50 个词/短语即可。

### 置信度三级

| 级别 | 判定 | 使用方式 |
| - | - | - |
| 确证 | ≥3 处独立出现，或 ≥3 篇出现 | 写作时强制执行 |
| 观察 | 1-2 篇出现，趋势明显但覆盖不足 | 写作时默认遵循，允许按任务微调 |
| 推断 | 单篇或零星出现，或由少量证据外推 | 供参考，交付时点明依据 |

每份分层产物末尾附置信度说明，说明哪些结论是哪一级、语料局限是什么。

## 一、语言DNA.md

> 回答"句子怎么写"。

### 提取项

**1. 高频词与套语（30-50 个）**

- 动词类："抓、推、盯、落"等高频动作词及其搭配（"抓落实/抓整改"）。
- 修饰类：高频副词与程度词（"进一步、扎实、切实、持续"），记录实际搭配。
- 四字格清单：摘录语料实际使用的四字格（"统筹推进、精准发力、闭环管理"），注意区分该来源惯用与政策文件搬用。
- 套语清单：起承转合的固定短语（"总的看、刚才、借此机会、下面我讲"）。

**2. 句式清单**

- "要"字句、"进一步"句、"在……上下功夫"句等，各摘 2-3 个原句，标明使用场景。
- 排比句式：结构模板（如"更+形容词"三连、"从……到……"），标注典型密度。
- 设问、反问、引用句：有无、怎么用。
- 数字概括句："三个X""四个X"的归纳习惯。

**3. 句长与节奏**

- 典型句长区间（目测即可，如"长句多在 40-60 字，部署段常用 15 字内短句收尾"）。
- 短句使用时机：何时突然收短（强调、转折、部署收束）。
- 段落长度与节奏：讲话是短段快转还是长段缓推；论文是长句铺陈还是短句递进。

**4. 称呼与自称**

- 对上、对下、对平级、对听众的称呼体系。
- 自称（我/我们/笔者/本文/本研究/本单位），何时切换。

**5. 语气强度分布**

- 命令式（必须/要/务必）、期望式（希望/争取/力争）、缓和式（建议/可/宜）的使用场合。

**6. 标点习惯**

- 引号（提法是否都加引号）、书名号（文件引用方式）、括号（补充说明还是注释）、顿号密度、冒号用法。

### 产出格式

每节"规则 + 例证（标注来源）"。末尾附语言层小结：用三五句话概括此人的句子"手感"，这段话是写作前找语感的锚。

## 二、结构模板.md

> 回答"文章怎么搭"。按体裁分节；同一体裁内再按场合分模板。

### 操作

1. **逐篇画骨架**：对每篇样文标注——开头（类型+字数）→ 主体（分几块、各块功能与字数占比、分条方式）→ 结尾（收束方式）。骨架中间标出过渡句原文。
2. **归并模板**：骨架相同或相近的归为一个模板。每个模板含：适用场合、骨架图（含各部分字数比例）、分条与过渡句式原文、允许的变体、禁忌（该来源不会用的开头/结尾）。
3. **对齐体裁细则**：骨架参照 `genre-guide.md`，但以语料实测为准——语料与通用骨架不一致时，记语料的。

### 产出格式

```
## 模板名（体裁+场合）
适用：……
骨架：
  开头（约X%）：功能 + 常用起手句原文
  主体（约X%）：分块方式 + 分条样式 + 过渡句原文
  结尾（约X%）：收束方式 + 常用收束句原文
变体：……
禁忌：……
例证来源：文件A、文件B
```

## 三、立场与认知.md

> 回答"话怎么说、事怎么摆"。这是公文与讲话复刻的核心，也是小语料下最需要标注"推断"的一层。

### 提取项

**1. 议题侧重**：反复强调什么、什么放最前面说、什么只一笔带过、什么从不谈。

**2. 价值排序**：遇到多目标时先保什么（如"安全第一还是进度第一"），从任务部署的先后和篇幅占比读出。

**3. 表述口径库（重中之重）**

- 固定提法：对战略、政策、重点工作的标准表述，逐条原文摘录（如某提法全称带引号、某文件用全称不用简称）。
- 惯用短语：成绩怎么说、问题怎么说、要求怎么说（"总体向好/稳中有进/仍有差距"各自的等级与使用场合）。
- 术语写法：首选写法与禁用写法对照。
- 禁用清单：语料中从未出现的表述——AI 高频套话（"赋能、闭环、抓手、颗粒度、底层逻辑"等）若语料中不存在，列入禁用清单。
- 口径敏感点：涉及上级精神、重大提法、敏感事项的表述，标注"此提法不得改动"。

**4. 素材与引用偏好**

- 引什么：数据、政策文件、典故、名言、身边案例的比例。
- 数据使用方式：精确值还是约数、同比/环比习惯、数据放在段首还是段尾。
- 引用格式：文件引用是全称+书名号还是简称。

**5. 成绩与问题的表述方式**：肯定句式、归因方向、问题部分的分寸等级、是否点名。

**6. 核心命题（3-5 条）**：贯穿多篇的非显而易见的判断（不是"发展很重要"，而是"X 问题要靠 Y 机制解决"这类该来源独有的看法）。小语料下至少给 2 条，全部标"推断"。

## 四、排版规范.md

> 回答"版面什么样"。

### 提取项

1. **标题编号体系**：实测该来源的层级写法（"一、（一）1.（1）"还是"1. 1.1"还是无编号小标题），各层字体加粗等排版特征（docx/pdf 可见时）。
2. **标题风格**：各级标题的句式（对仗/动宾/名词短语）、字数、是否带标点。
3. **段落节奏**：段均字数、是否有"一句一段"的强调用法。
4. **公文格式要素**（语料可见时）：主送机关写法、成文日期与落款位置、附件说明格式。
5. **论文格式要素**（语料可见时）：摘要与关键词的排版、图表编号与标题位置、参考文献著录格式与标点。
6. **强调手段**：加粗、黑体、引号强调、破折号插入语的实际用法与频率。

.docx/.pdf 原件比转换后的 .md 更能反映排版，提取排版规范时尽量回看原件。

## 五、跨层一致性检查

四份产物完成后做一次交叉核对：

- 结构模板里的过渡句式与语言DNA的套语清单是否一致（同一句式两处表述应相同）。
- 口径库的术语写法与排版规范的标题风格是否冲突。
- 置信度说明是否覆盖四份产物（每份都要有）。
- 删除各层之间重复的规则，重复内容归入更合适的一层。
