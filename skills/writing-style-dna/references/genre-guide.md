# 体裁细则

体裁判定先于一切分析：不同体裁的提取重点、结构模板和去AI味豁免都不一样。本文件给出各体裁的骨架、语言特征和提取重点。分析产物（结构模板、排版规范）中遇到多体裁混合时，按体裁分节。

## 一、领导讲话稿

讲话是"说给人听"的文体，口语节奏 + 书面框架。同一人的讲话可能横跨数年，风格漂移明显，近期文本权重更高。

### 常见结构骨架（按场合）

**部署动员类**（工作会、推进会、动员会）：

```
开场定调（会议背景与意义，1段）
→ 第一部分：统一思想 / 肯定成绩 / 分析形势
→ 第二部分：重点任务部署（"一是……二是……三是……"或（一）（二）（三）分条，每条含具体抓手）
→ 第三部分：工作要求（加强领导、压实责任、强化保障、转变作风）
→ 结尾：号召或期望
```

**总结讲评类**（总结会、述职会）：回顾 → 成绩与亮点（分类+数据）→ 问题与不足（简短、留有余地）→ 下一步 → 要求。

**座谈会/调研类**：听取情况的回应 → 几点感受 → 几点意见（常为"三点"）→ 落实期望。

### 提取重点

- **称呼与自称**：对听众（同志们/各位/各位委员）与自称（我/我们/建议结合"我觉得""我强调三点"等第一人称句）。
- **"要"字句密度**：命令式强度分布（必须/要/应当/希望），这是讲话的语气骨架。
- **排比与四字格**：造势段落的排比结构（如"三个更""四个坚持"式）、四字格连用节奏。讲话排比是常规手段，密度以语料实测为准。
- **数字概括**："三个环节""四个一批""五个到位"式的数字归纳习惯。
- **引语偏好**：引用上级文件精神、政策原文、典故、名言的比例和方式。
- **口径**：对重大战略、重点工作的固定提法，逐条摘录原文。
- **成绩与问题表述**：肯定句式、归因方式（归功于谁）、问题部分是否点名、留有多大余地。

### 去AI味豁免

"一是……二是……"分条、排比造势、四字格连用、号召式结尾都是讲话惯例，不按通用去AI味规则处理，密度对照语料。

## 二、公文（通知/请示/报告/函/纪要/批复）

公文以文种定结构，格式和套语是硬规范。提取时先分文种。

### 文种结构与套语

| 文种 | 结构骨架 | 常用套语（必须逐字保留惯例） |
| - | - | - |
| 通知 | 缘由依据 → 事项（分条） → 执行要求 | "现将……通知如下""特此通知""请认真贯彻执行" |
| 请示 | 缘由 → 请示事项 → 结语 | "妥否，请批示""当否，请批示""特此请示" |
| 报告 | 缘由 → 主体（情况/工作/问题） → 结语 | "现将有关情况报告如下""特此报告" |
| 函（商洽/询问） | 缘由 → 事项 → 结语 | "特此函达""盼复""为盼" |
| 纪要 | 会议概况 → 议定事项（分条） → 其他 | "会议认为""会议指出""会议决定""会议要求" |
| 批复 | 引述来文 → 表态 → 依据与要求 | "你局《……》（文号）收悉""经研究，现批复如下" |

### 提取重点

- **格式要素**：标题三要素（发文机关+事由+文种）、主送机关、成文日期、落款；有红头版式时在排版规范中描述。
- **标题编号体系**："一、（一）1.（1）"四层体系及各层的使用习惯。
- **表态词**：本单位的表态词梯度与惯用等级（见 `rewrite-guide.md` 表态等级表），逐条摘录。
- **行文对象称谓**："你局/贵单位/各市（州）……"的称呼习惯；公文中不用"您"。
- **语气特征**：庄重平实、少修辞、多祈使与规范表述；议论抒情成分（AI 常见毛病）在本语料中的实际占比（通常为零）。

### 去AI味豁免

层级编号是格式规范不是AI味；文种套语必须保留；"拟""原则同意""不予"等表态词等级不得升降。

## 三、学术论文

### 结构骨架

```
题目 → 摘要（目的-方法-结果-结论四要素） → 关键词
→ 引言（研究背景漏斗：领域 → 现状与不足 → 本文工作）
→ 文献综述 / 相关工作
→ 方法（模型/实验设计/数据）
→ 结果（图表+统计检验）
→ 讨论（解释、局限、与已有研究对比）
→ 结论 → 参考文献
```

### 提取重点

- **摘要写法**：四要素是否齐全、句数、是否用"本文/本研究"开头、有无量化结果句。
- **Hedging 密度**："表明/提示/可能/在一定程度上/有待进一步"等限定语的使用频率与位置——学术文体的核心特征，改写时不得删除或加重。
- **术语一致性**：核心术语的首选译名/写法（建术语对照表放入表述口径库），同义混用情况。
- **引用风格**：GB/T 7714 或目标期刊格式；引用密度与引用位置（句尾/句中）；自我引用表述（"如文献[3]所述"）。
- **图表规范**：图1/表1 编号体例、三线表、图表标题位置、单位写法。
- **层级编号**："1. 1.1 1.1.1"体系，与公文体系不同，不得混淆。
- **人称与语态**："本文/本研究/笔者"还是零人称；被动与名词化是学术文体特征，一律保留。

### 去AI味豁免

"综上所述""本文认为""在一定程度上"是学术惯例，不按禁用起手式和翻译腔规则处理；被动句、名词化、长句一律不改。

## 四、工作总结与汇报材料

### 结构骨架

```
总述（一句到一段：总体完成情况，常带总量数据）
→ 主要工作与成绩（分块，每块"做法+数据+效果"）
→ 存在问题（2-4条，客观简短）
→ 下一步打算（分条，与问题呼应）
```

### 提取重点

- **数据密度**：总结类文本数据密度最高，"完成X%、同比增长X%"句式的使用方式。
- **小标题风格**：动宾对仗（"抓改革、促发展"）、字数、是否押韵、是否带编号。
- **成绩表述方式**：做法与效果的衔接句式（"通过……，实现了……"的实际使用情况）、是否归功表态。
- **问题表述**：措辞分寸（"仍有差距/有待提升/存在短板"的等级）、是否具体到事。

## 五、评论文章与其他

参照新媒体评论处理：开头 hook 类型、论证结构（立论-论据-让步-结论）、例子与数据的配比、结尾方式。用户工作中有其他固定文体（方案、简报、信息稿、讲话提纲）时，按上述框架现场归纳并补入本档案的 `结构模板.md`。

## 六、跨体裁通用提取点

无论什么体裁，以下四点都要提取：

1. **称呼与自称体系**：对不同对象怎么称呼、自己怎么自称。
2. **表述口径库**：固定提法、惯用短语、术语写法，逐条原文摘录。
3. **标题编号体系**：所在单位/作者的编号惯例。
4. **过渡句式**：段与段、部分与部分之间的衔接套语（"下面我讲三点""综上所述""在此基础上"），逐条摘录原文。
